# R.M. Maneesha Kalpani - Portfolio

1. Install Node.js (version 18 or newer).
2. Open a terminal in this folder and run: npm install
3. Start the site: npm start
4. Open http://localhost:3000

Included:
- public/images/profile.jpg and about.jpg (your photos)
- public/my-cv.pdf (your CV, used by the Download CV button)
- Your three projects in the "My Work" section
